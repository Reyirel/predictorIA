# Guía de Contribución

Debido a la naturaleza del proyecto y las restricciones de licencia, actualmente **no se aceptan contribuciones externas** a este repositorio. El código se proporciona únicamente con fines de visualización y referencia académica.

## Restricciones

- No se aceptarán pull requests
- No se procesarán solicitudes de cambios
- No se responderán issues relacionados con mejoras o nuevas características

## Reportes de Problemas

Si encuentra errores conceptuales significativos en la metodología o documentación, puede reportarlos creando un issue con la siguiente información:

1. Descripción clara y concisa del problema
2. Ubicación exacta del error (archivo, línea)
3. Fundamento científico/técnico que sustenta que existe un error
4. Referencias bibliográficas que respalden su observación

Los reportes que cumplan estos criterios serán revisados por el equipo del proyecto, aunque no se garantiza ninguna acción o respuesta.

## Contacto

Para consultas específicas sobre el uso académico o investigativo de este material, puede contactar al autor principal a través de los canales oficiales especificados en el perfil del repositorio.

## Agradecimientos

Agradecemos su interés en este proyecto. Si desea citarlo en publicaciones académicas, por favor utilice el formato adecuado según las indicaciones proporcionadas en la sección correspondiente del README.
